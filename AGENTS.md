# Agent instructions

Before running Rails commands on the VPS, read
[docs/RAILS_VPS_COMMANDS.md](docs/RAILS_VPS_COMMANDS.md).
Do not use root as a fallback for Bootsnap, Ruby or permission errors.
Preserve existing local changes and use the `rtk` prefix for shell commands.
This application is dormant; do not start Rails in production or reactivate it without its documented security gate.
